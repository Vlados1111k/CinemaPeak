# Проєкт CinemaPeak — Лабораторна робота №36

Ця гілка репозиторію присвячена виконанню **Лабораторної роботи №36**, метою якої є впровадження автоматизованого тестування бізнес-логіки системи кінотеатру та налаштування метрик покриття коду (Code Coverage).

## Основні завдання лаби:
1. Покриття сервісів розрахунку вартості квитків та аналітики юніт-тестами.
2. Інтеграція інструменту `coverlet` для відстеження відсотків покриття коду.
3. Налаштування CI/CD (GitHub Actions) для автоматичного прорахунку тестів при кожному коміті.

---
