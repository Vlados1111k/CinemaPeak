# CinemaPeak — Cinema Management & Analytics System

**CinemaPeak** — це сучасна, високопродуктивна консольна система для автоматизації роботи кінотеатру, обліку продажів квитків, керування сеансами та глибокої аналітики касових зборів. Проєкт реалізований на платформі .NET з дотриманням принципів об'єктно-орієнтованого проєктування (SOLID, DRY, KISS) та архітектурного розділення логіки.

---

## Основний функціонал (Key Features)

* **Керування кінозалом та сеансами:** Гнучке налаштування розкладу фільмів, типів залів та категорій місць.
* **Інтерактивна система квитків:** Покупка та бронювання місць, підтримка різних типів квитків (дитячий, студентський, VIP) з автоматичним розрахунком знижок та надбавок.
* **Аналітика та звітність (Financial Analytics):**
    * Підрахунок загального виторгу кінотеатру.
    * Аналіз популярності фільмів та заповнюваності залів.
    * Генерація детальних фінансових звітів у форматі `Report.md`.
* **Зручний консольний інтерфейс:** Інтерактивне меню з навігацією для адміністраторів та касирів.
* **Надійна кодова база:** Логіка повністю покрита Unit-тестами за допомогою xUnit та Coverlet.

## Структура проєкту (Project Architecture)

Проєкт розділений на логічні шари (модулі) для спрощення підтримки та масштабування:

```text
CinemaPeak/
├── src/
│   ├── CinemaPeak.Core/       # Бізнес-логіка: сутності (Movie, Ticket, Session), інтерфейси, сервіси
│   └── CinemaPeak.Console/    # Шар представлення: консольне меню, взаємодія з користувачем, запуск
├── tests/
│   └── CinemaPeak.Tests/      # Юніт-тести для перевірки логіки розрахунків та сервісів
├── .github/workflows/
│   └── ci.yml                 # Конфігурація CI (автоматичний білд та прорахунок % покриття тестів)
├── README.md                  # Документація проєкту
└── .gitignore                 # Конфігурація ігнорування сміттєвих файлів розробки
