# User Guide - CinemaPeak

Застосунок працює у зручному консольному режимі.

## Як користуватися меню:
1. **Запуск застосунку:** Що б запустити файл потрібно ввести команду`dotnet run --project src/CinemaPeak.ConsoleApp`.
2. **Перегляд доступних місць:** Оберіть пункт меню `1`. Програма покаже поточну карту залу.
3. **Бронювання квитків:**
   * Натисніть `2`.
   * Введіть номер ряду (від 1) та місця (від 1).
   * Оберіть тип квитка (Стандартний чи VIP).
   * Вкажіть, чи ви є студентом (для активації знижки 20%).
4. **Перегляд аналітики:** Пункт меню `3` виводить загальну фінансову виручку та кількість проданих квитків.
5. **Вихід:** Пункт `0` автоматично зберігає всі дані у файл `tickets.json` та безпечно завершує сесію.
