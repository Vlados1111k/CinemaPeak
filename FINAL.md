# Фінальний технічний звіт по проєкту CinemaPeak

## 1. Інженерні компроміси (Trade-offs)
Під час розробки архітектури сховища даних було обрано збереження у форматі JSON-файлу через `JsonDataStore`. 
* **Плюси:** Відсутність потреби розгортати важкі СУБД (SQL Server/PostgreSQL), швидкість налаштування для MVP, легкість тестування через тимчасові файли.
* **Мінуси:** При обсягах даних понад 100 000 квитків операції повного перезапису файлу стануть неефективними за пам'яттю ($O(N)$). Для майбутнього розширення системи передбачено легку заміну шару на EF Core завдяки інтерфейсу `ITicketRepository`.

## 2. Складні моменти під час розробки
Найбільшим викликом була реалізація стійкої поліморфної десеріалізації абстрактних класів. Проблему вирішено за допомогою сучасних нативних атрибутів метаданих .NET 10 (`JsonDerivedType`), що дозволило зберегти чистоту Domain-шару без підключення сторонніх бібліотек на кшталт Newtonsoft.Json.

## 3. Висновок
Проєкт `CinemaPeak` успішно реалізовано як завершений навчальний продукт.
