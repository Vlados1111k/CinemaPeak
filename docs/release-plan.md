# План релізу v1.0 - CinemaPeak

## 1. Scope
* **Реалізовано:** Повний цикл бронювання квитків (Standard/Vip), розрахунок знижок (Strategy), файлове сховище (`JsonDataStore`) з поліморфною серіалізацією .NET 10 та стійкість до пошкоджень файлів.
* **Перенесено "після курсу":** Графічний інтерфейс (GUI/WPF), інтеграція з реальними платіжними шлюзами, автентифікація користувачів за ролями.

## 2. Допустимий технічний борг
* Консольне меню в `Program.cs` використовує лінійну структуру `switch-case` для обробки команд. Це допустимо для консольного MVP.

## 3. Статус освоєння тем курсу
* **Повністю закрито:** Поліморфізм, чиста архітектура, Юніт/Інтеграційне тестування (xUnit/Moq), JSON-persistence.
* **Частково покрити:** Продуктивність колекцій та LINQ, XML-документація (буде виправлено в поточному спринті).
