# Обґрунтування вибору структур даних та аналіз продуктивності

## 1. Сценарій: Побудова аналітичного звіту зайнятих рядів
В `AnalyticsService.GetOccupiedRowsLog()` інтегровано структуру даних `HashSet<int>`.

## 2. Порівняльний аналіз
* **Альтернатива (List + .Contains):** При додаванні елементів нам доводилося б перевіряти `if (!list.Contains(id))`, що дає складність алгоритму **$O(N)$** для кожного елемента, а сумарно для звіту - **$O(N^2)$**.
* **Обране рішення (HashSet):** Операція `.Add()` у хеш-таблиці має середню складність **$O(1)$**. Загальна складність побудови звіту становить **$O(N)$**, що є ідеальним показником продуктивності.
* **LINQ Агрегація:** Метод `GetTotalRevenue()` використовує оптимізований внутрішній ітератор LINQ `.Sum()`, що мінімізує виділення пам'яті (Allocation) в .NET 10.
